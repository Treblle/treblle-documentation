# 2025 Changelog

This page tracks notable changes to the Treblle main website, APIs, and documentation.

---

## Webinar Registration — Job Position & Company Fields Added

**Type:** Feature  
**Affected areas:** Webinar registration form, Webinar API routes

### What changed

The webinar registration form and all associated API routes now collect two additional fields from registrants:

- **Job Position** — the registrant's job title or role
- **Company** — the registrant's company name

### Form behaviour

Both fields are displayed in the registration form and are **required** to enable form submission. The submit button remains disabled until all required fields — including Job Position and Company — are filled in.

### API behaviour

At the API level, both `jobPosition` and `company` are optional fields. When provided, they are conditionally written to the associated Notion database record:

| Notion Property | API Field | Type |
|-----------------|-----------|------|
| `Job Position` | `jobPosition` | `rich_text` |
| `Company` | `company` | `rich_text` |

If either field is omitted from the request body, the corresponding Notion property is not set.

### Affected routes

- `POST /api/events/webinars/join/zoom-webinars`
- `POST /api/events/webinars/join/zoom`
- `POST /api/events/webinars/notion`
