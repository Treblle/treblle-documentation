# Changelog 2025

## How It Works Page

### fix: cta button documentation

The **"View Documentation"** secondary CTA button on the [How It Works](https://treblle.com/how-it-works) page now correctly links to the Treblle documentation site at `https://docs.treblle.com/`.

Previously, the `linkSecondary` prop was not set on the `Hero` component used on this page, meaning the secondary button had no destination. This has been resolved by passing `linkSecondary="https://docs.treblle.com/"` to the component.

**Affected file:** `app/(web)/how-it-works/page.tsx`
