# Agents

The **Agents** page gives you a full view of all AI-powered automation jobs running against a specific API. Agents perform complex tasks on your behalf — from generating an OpenAPI specification from live traffic to refactoring your codebase — so your team can move faster without manual work.

## Overview

The Agents page shows four status widgets at the top, giving you an instant picture of your automation workload:

Click the **New Agent** button in the top-right corner to open the agent type selector. Choose from the following agent types:

<NoteCard>
Most agent types require a GitHub connection. Connect GitHub in **Workspace Settings** before running agents that modify or push code.
</NoteCard>

## Agent Job Cards

Each job in the list shows:

- **Agent type** — what the agent was asked to do
- **Status** — Pending, In Progress, Completed, or Failed
- **Started at** — timestamp of when the job began executing
- **Created by** — the workspace member who triggered the job

Click on a job card to open the **Job Drawer**, which shows the full execution log, output, and any files or artifacts produced by the agent.

## Filtering and Sorting

Use the **Filter** button to narrow down jobs by status or agent type. Use the **Sort** dropdown to order the list by creation date or status.

<TipCard>
If a job fails, open the job drawer to review the error log. Common causes include missing GitHub permissions or an API that hasn't received enough traffic for the agent to work with.
</TipCard>
