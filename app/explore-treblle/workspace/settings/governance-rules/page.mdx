# Governance Rules

The **Governance Rules** settings page lets you define and customize the rules used to evaluate API governance scores across your workspace. Rules affect how APIs are scored and graded on the Governance dashboard.

<ImageCard src="/Settings - governance-rules.png" alt="Governance Rules Settings" />

## Rule Categories

Governance rules are organized into the following categories:

### Security
Rules that evaluate authentication, encryption, and security headers.

### Design
Rules that assess API structure, naming conventions, versioning, and documentation quality.

### Performance
Rules that measure response time thresholds and payload size limits.

### AI Ready
Rules that determine how well APIs are structured for AI and automation use cases.

---

## Managing Rules

### Enabling and Disabling Rules
Toggle individual rules on or off for your workspace.

### Rule Weight
Adjust the weight of each rule to influence its impact on the overall governance score.

### Custom Rules
Enterprise plans support adding custom rules tailored to your organization's standards.
