# Consumers

The **Consumers** tab provides a real-time overview of how your APIs are being used by individual consumers. It helps you understand usage patterns, identify key consumers, and measure the impact of API performance and issues on your users.

<ImageCard src="/Home - customers.png" alt="Home Consumers Dashboard" />

## Consumer Overview Cards

Four top-level metrics summarize consumer activity across the workspace:

<ImageCard src="/Home - customers - 1.png" alt="Consumer Overview Cards" />

### New Consumers
Number of new consumers interacting with your APIs.

- Indicates growth in API adoption
- Helps track onboarding trends

### Active Consumers
Total number of consumers actively using your APIs.

- Reflects real usage, not just registered users
- Useful for monitoring engagement

### Top Consumer
Highlights the consumer generating the highest API usage.

- Identifies key accounts and heavy users

### Avg. Requests per Consumer
Shows the average number of API requests per consumer.

- Helps measure usage intensity
- Indicates load distribution across consumers

## Consumer Usage Insights

<ImageCard src="/Home - customers - 2.png" alt="Consumer Usage Insights" />

### Top Consumers
Lists consumers with the highest number of API requests.

- **Consumer**: Name or identifier of the consumer
- **Requests #**: Total number of requests generated

Helps identify:
- High-value consumers
- Potential heavy-load contributors

### Consumer Breakdown per API
Shows how API usage is distributed between consumers and AI agents.

- **API**: Name of the API
- **Consumers %**: Percentage of requests from human users
- **AI Agents %**: Percentage of requests from automated systems

Provides insight into:
- Human vs automated traffic
- AI adoption across APIs

### API Consumers
Visual breakdown of API usage by consumer type.

- **Consumers**: Human users interacting with APIs
- **AI Agents**: Automated or AI-driven consumers

## Risky Consumers

This section highlights consumers affected by API issues.

<ImageCard src="/Home - customers - 3.png" alt="Risky Consumers" />

- **Consumer**: Name or identifier of the affected consumer
- **API**: API involved in the issue
- **Failed Requests #**: Number of failed or problematic requests

Helps you:
- Understand business impact of issues
- Prioritize fixes based on consumer importance
- Identify recurring problem areas

---

## Filters & Controls

At the top-right of the dashboard, you can filter data by:

- **Environment** (e.g. production, staging)
- **Category** (e.g. end user, department)
- **Time range** (e.g. last 24 hours)
